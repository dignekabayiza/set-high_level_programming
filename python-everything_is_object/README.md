# python-everything_is_object

Python exercises about objects, types, and identity.

## Tasks
- 0-answer.txt: the function used to get the type of an object
- 1-answer.txt: the function used to get the variable identifier (memory address in CPython)
- 2-answer.txt to 28-answer.txt: answers about object identity, mutability and tuples
- 19-copy_list.py: returns a copy of a list
- 100-magic_string.py: returns "BestSchool" repeated once more on each call
- 101-locked_class.py: class that only allows the first_name instance attribute
- 103 to 106 line files: answers about how CPython creates int and string objects
