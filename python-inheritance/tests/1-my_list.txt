The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

Normal case:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Negative numbers and duplicates:

    >>> my_list = MyList([3, -1, 3, 0, -5])
    >>> my_list.print_sorted()
    [-5, -1, 0, 3, 3]
    >>> print(my_list)
    [3, -1, 3, 0, -5]

Already sorted:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

It is a real list subclass:

    >>> issubclass(MyList, list)
    True
