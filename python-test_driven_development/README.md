# Python - Test-driven development

This directory contains my work on test-driven development in Python 3, using doctest.

## Files

- `0-add_integer.py`: a function `add_integer(a, b=98)` that adds two integers or floats, casting floats to integers.
- `tests/0-add_integer.txt`: doctest cases for `0-add_integer.py`.
- `2-matrix_divided.py`: a function `matrix_divided(matrix, div)` that divides all elements of a matrix by a number, rounded to 2 decimal places.
- `tests/2-matrix_divided.txt`: doctest cases for `2-matrix_divided.py`.
- `3-say_my_name.py`: a function `say_my_name(first_name, last_name="")` that prints `My name is <first name> <last name>`.
- `tests/3-say_my_name.txt`: doctest cases for `3-say_my_name.py`.
- `4-print_square.py`: a function `print_square(size)` that prints a square with the character `#`.
- `tests/4-print_square.txt`: doctest cases for `4-print_square.py`.
- `5-text_indentation.py`: a function `text_indentation(text)` that prints a text with 2 new lines after each `.`, `?` and `:`.
- `tests/5-text_indentation.txt`: doctest cases for `5-text_indentation.py`.
- `6-max_integer.py`: a function `max_integer(list=[])` that returns the max integer of a list.
- `tests/6-max_integer_test.py`: unittest cases for `6-max_integer.py`.
